# Пахлавон — корпоративный сайт охранного агентства

Полноценный многостраничный сайт (TJ / RU / EN), со светлой и тёмной
liquid-glass темой, официальным логотипом бренда, анимированными страницами
услуг и админ-панелью с управлением всем контентом. Реализован строго по
брендбуку «Пахлавон» (графит / кремовый / золото).

## Стек

**Ванильный HTML + CSS + JS**, без сборки и фреймворков. Сайт публикуется на
GitHub Pages (как и весь репозиторий), не требует обязательного бэкенда (есть
опциональный — см. ниже), даёт минимальный вес и максимальную скорость.
Анимации услуг — **SVG + CSS** (масштабируемость, реакция на тему через
CSS-переменные, анимируются только `transform`/`opacity`).

### Каждая страница загружает одинаковый набор скриптов

```html
<script src="assets/js/i18n.js"></script>
<script src="assets/js/i18n-pages.js"></script>
<script src="assets/js/content.js"></script>
<script src="assets/js/vacancies.js"></script>
<script src="assets/js/api.js"></script>
<script src="assets/js/animations.js"></script>
<script src="assets/js/common.js"></script>
<script src="assets/js/page-<тип-страницы>.js"></script>  <!-- последним -->
```

`Common.boot(renderPage, metaPath)` отвечает за тему, язык, шапку/бургер/
to-top, контактные ссылки, синхронизацию с сервером и scroll-reveal;
`renderPage(t, lang)` — функция конкретной страницы, которая заполняет её
динамические блоки. Страницы услуг используют один общий
`page-service-detail.js`, параметризованный атрибутом `data-service` на
`<body>`.

## Логотип и фирменный стиль

Используется **официальный логотип бренда** (вордмарк PAHLAVON со
щитом вместо буквы «O», предоставлен заказчиком) — растровый файл с
прозрачным фоном в двух перекрашенных вариантах: `logo-cream.png` (тёмная
тема) и `logo-graphite.png` (светлая тема), переключаются через CSS по
`[data-theme]`. Из этого же логотипа вырезан отдельно сам щит — он
используется **точечно**, в ограниченных случаях: фавикон, OG-обложка,
эмблема на странице «О компании», иконка входа в админ-панель — но не как
основной логотип в шапке/подвале.

Фон сайта — атмосферный слой (`.atmosphere`) с мягким золотым/графитовым
свечением, радар-кольцами и тонкой сеткой, фиксированный за контентом (без
жёстких геометрических паттернов). Карточки выполнены в стиле **liquid glass**:
полупрозрачный фон + `backdrop-filter: blur()` + мягкая обводка/подсветка,
цвета берутся из CSS-переменных темы (`--glass-bg`, `--glass-border` и т.д.),
со фолбэком на непрозрачный фон в браузерах без `backdrop-filter`.

## Раздел «Услуги» — технические данные

Подробный контент 6 из 8 страниц услуг (видео, СКУД, пожарная, пультовая,
физическая охрана, GPS) взят из presentation-брифа заказчика и переведён на
TJ/EN с сохранением структуры (что это и зачем → как работает → оборудование
→ применение → итог). Для «Диагностика и ремонт» и «Безопасность
мероприятий», по которым подробных слайдов не было, контент написан в том
же стиле и глубине. Термин «ИИ» заменён на **«глубокий анализ»** везде по
правилу бренда.

## Админ-панель

Даёт управление всем сайтом:

| Вкладка | Что делает |
|---|---|
| **Контент сайта** | Редактирование всего текста сайта на 3 языках — все i18n-ключи всех 18 страниц, сгруппированы по разделам с вложенными подгруппами (например, каждая из 8 страниц услуг — отдельная вложенная группа). Сохранение применяется на сайте сразу. |
| **Вакансии** | Добавление / изменение / удаление вакансий (с переводами на RU/TG/EN), сброс к стандартному набору. |
| **Отклики** | Заявки с вакансий и с формы аудита на «Контактах» — в одном списке; экспорт в JSON/CSV, удаление. |
| **Контакты и бренд** | Телефон, e-mail, Telegram, WhatsApp, Instagram — подставляются во все ссылки связи на сайте. |

Вход: пароль по умолчанию **`pahlavon2024`**.

### Два режима работы

Переключаются полем **«Сервер (бэкенд)»** на вкладке «Контакты и бренд»:

1. **Офлайн (по умолчанию).** Адрес API не задан. Контент/вакансии/отклики
   и вход — в `localStorage` браузера. Работает на чистом GitHub Pages и
   даже через `file://` без сервера, но данные не синхронизируются между
   устройствами и посетителями, а вход проверяется в браузере (не настоящая
   защита).
2. **Серверный (рекомендуется для прода).** Указан адрес API-сервера из
   папки [`backend/`](backend/). Тогда вход проверяется на сервере (пароль →
   подписанный HMAC-токен), контент/настройки/вакансии хранятся в БД и видны
   **всем** посетителям и на всех устройствах, отклики с форм попадают на
   сервер и видны в админке.

Сервер — лёгкий, **без внешних зависимостей** (Node 22+, `node:http` +
`node:sqlite` + `node:crypto`). Деплой (Docker / Render / Railway /
systemd) и настройка описаны в [`backend/README.md`](backend/README.md).

## Локальный просмотр

```bash
cd pahlavon
python3 -m http.server 8000
# открыть http://localhost:8000
```

Сайт также открывается напрямую двойным кликом по `index.html` (`file://`,
без какого-либо сервера) — все страницы и админка работают офлайн на
`localStorage`.

## Что подключить на проде (вне статики)

- **Отправка форм:** сейчас демо-режим (без бэкенда) сохраняет заявку в
  `localStorage` и открывает Telegram с заполненным текстом. С бэкендом —
  заявки сразу попадают на сервер. На проде также можно подключить e-mail
  (`sales@pahlavon.tj`) и/или Telegram Bot API на стороне сервера, добавить
  Cloudflare Turnstile / reCAPTCHA.
- **Аналитика:** вставить Yandex.Metrica / GA4 c целями на отправку формы и
  клики по телефону/мессенджерам.
- **Контент:** заменить иллюстративные кейсы/отзывы/логотипы партнёров и
  точный адрес офиса на реальные данные.

## Принятые по умолчанию решения

| Вопрос | Решение по умолчанию |
|---|---|
| Язык по умолчанию | Русский (с автоопределением по браузеру) |
| Объём услуг | Все 8, каждая на отдельной странице |
| Структура | Полноценный многостраничный сайт |
| Куда заявки | Демо → localStorage + Telegram; с бэкендом → сервер |
| Стек | Статика без сборки (HTML/CSS/JS) + опциональный Node-бэкенд |

Эти решения легко изменить — весь текст вынесен в `i18n.js`/`i18n-pages.js`
(и редактируется из админки), услуги и структура страниц — в соответствующих
`page-*.js`.

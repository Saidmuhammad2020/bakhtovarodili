# Пахлавон — корпоративный сайт охранного агентства

Мультиязычный (TJ / RU / EN) сайт-лендинг со светлой и тёмной темой,
анимированными разделами услуг, формой заявки и калькулятором потерь.
Реализован строго по брендбуку «Пахлавон» (графит / кремовый / золото).

## Стек

Выбран **облегчённый вариант B** из ТЗ §14 — статика без сборки:
**ванильный HTML + CSS + JS**. Причины: сайт публикуется на GitHub Pages
(как и весь репозиторий), не требует бэкенда, даёт минимальный вес и
максимальную скорость (целевые Lighthouse из ТЗ §11). Анимации услуг —
**SVG + CSS** (масштабируемость, реакция на тему через CSS-переменные,
анимируются только `transform`/`opacity`).

## Структура

```
pahlavon/

├── 404.html              # страница 404 в фирменном стиле
├── robots.txt, sitemap.xml
└── assets/
    ├── css/styles.css    # дизайн-система, токены тем (ТЗ §6.2), компоненты

    ├── js/animations.js  # 8 SVG-анимаций услуг + логотип/эмблема/паттерн (ТЗ §7)
    ├── js/app.js         # i18n-движок, темы, рендеринг, формы, калькулятор
    └── img/              # favicon.svg, og-cover.svg
```

## Что реализовано из ТЗ

- **§3 Бренд:** цвета, типографика Nunito Sans, логотип-леттеринг и эмблема (SVG), треугольный паттерн.
- **§4 Мультиязычность:** TJ/RU/EN на ключах, автоопределение по `navigator.language`, сохранение выбора, `?lang=` и `hreflang`. Переключение не сбрасывает раздел.
- **§6 Темы:** тёмная (по умолчанию) и светлая, токены CSS-переменными, анти-FOUC, `prefers-color-scheme`, сохранение выбора.
- **§7 Услуги:** 8 карточек с индивидуальными анимациями, описанными в ТЗ; запуск по вьюпорту, пауза вне экрана, статичный ключевой кадр как `prefers-reduced-motion` fallback.
- **§8 Секции:** Hero, О компании (счётчики count-up), Преимущества, Процесс, Кейсы, Партнёры, Отзывы, FAQ-аккордеон, Калькулятор потерь, CTA, Контакты, Подвал.
- **§9 Формы:** валидация на лету с локализацией, маска `+992`, honeypot, согласие на обработку ПДн, экран успеха.
- **§10–13:** mobile-first адаптив, lazy-карта, семантика, ARIA, видимый focus, поддержка `prefers-reduced-motion`, LocalBusiness/SecurityService JSON-LD.

## Локальный просмотр

```bash
cd pahlavon
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Что подключить на проде (вне статики)

- **Отправка форм** (`app.js`, обработчик submit): сейчас демо-режим открывает
  Telegram с заполненным текстом. На проде заменить на серверный роут →
  e-mail (`sales@pahlavon.tj`) и/или Telegram Bot API; добавить
  Cloudflare Turnstile / reCAPTCHA (ТЗ §9.1).
- **Аналитика:** вставить Yandex.Metrica / GA4 c целями на отправку формы и
  клики по телефону/мессенджерам (ТЗ §9.3).
- **Контент:** заменить иллюстративные кейсы/отзывы/логотипы партнёров и
  точный адрес офиса на реальные данные (ТЗ §15, §17).

## Открытые вопросы ТЗ §17 — принятые по умолчанию решения

| Вопрос | Решение по умолчанию |
|---|---|
| Язык по умолчанию | Русский (с автоопределением) |
| Объём услуг | Все 8 |
| Структура | Лендинг (отдельные страницы услуг — следующий этап) |
| Куда заявки | Демо → Telegram; на проде e-mail/бот |
| Калькулятор потерь | Включён |
| Стек | Вариант B (статика) |

Эти решения легко изменить — все тексты вынесены в `i18n.js`, услуги
конфигурируются массивом в `app.js`.
